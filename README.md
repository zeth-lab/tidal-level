# 조수간만 대지레벨

디자인스튜디오2 · 조수간만 인공섬 1단계 대지레벨 도구.

- 사이트: https://zeth-lab.github.io/tidal-level/
- 12m 큰 칸으로 섬 영역을 고르면 조간대 가운데 높이(기본 EL +2)의 땅이 생겨요.
- 12·6·4·3·2·1m 칸 단위로 올리기·내리기·평탄·다듬기.
- 섬 군집: 목차 01 아래에서 12m 칸을 묶어 군집을 만들고, 군집마다 축을 따로 회전·이동. 땅·그리드·건물·길이 함께 따라감.
- 길·회랑: 1m 그리드 점 맞춤, Shift = 앞 점에서 가로·세로로만. 회랑·건물마다 기둥 너비·간격 조절.
- 수위를 간조↔만조로 움직이며 조하대·조간대·조상대·대지 면적 확인.
- 버전은 브라우저(IndexedDB)에 저장. 다른 컴퓨터로 옮길 땐 JSON 내보내기/불러오기.
- 실시간 공유: 왼쪽 목차 09 → 방 이름으로 '조작하기'. 보는 사람은 `#room-방이름` 링크. 로그인 없음 (PeerJS 공개 연결 서버 사용).
- 시각 막대(수위 막대 아래): 낮·밤 하늘과 햇빛, 조석 연동, ▶ 하루 재생. 녹화에 '하루 낮·밤', '고른 길 따라 걷기(사람 시점)' 추가.
- 건물: 15° 단위 회전(R), 원형·타원 모양(허브 등), 크기·높이·색·투명도 개별 지정, 평지붕(투명도·처마) 켜고 끄기. 연못·개인 풀(석조 수조), 자유 오브젝트.
- 편집: 고른 언덕을 비탈째 끌어 옮기기(M). 길·면도 색 직접 지정·투명도. 보기: 사실적인 바다(물결·반사) 켜고 끄기.
