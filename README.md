# 조수간만 대지레벨

디자인스튜디오2 · 조수간만 인공섬 1단계 대지레벨 도구.

- 사이트: https://zeth-lab.github.io/tidal-level/
- 12m 큰 칸으로 섬 영역을 고르면 조간대 가운데 높이(기본 EL +2)의 땅이 생겨요.
- 12·6·4·3·2·1m 칸 단위로 올리기·내리기·평탄·다듬기.
- 수위를 간조↔만조로 움직이며 조하대·조간대·조상대·대지 면적 확인.
- 버전은 브라우저(IndexedDB)에 저장. 다른 컴퓨터로 옮길 땐 JSON 내보내기/불러오기.
- 실시간 공유: 왼쪽 목차 09 → 방 이름으로 '조작하기'. 보는 사람은 `#room-방이름` 링크. 로그인 없음 (PeerJS 공개 연결 서버 사용).
